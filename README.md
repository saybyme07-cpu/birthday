# SayByMe – Birthday Edition 🎉🎂

An interactive, magical birthday celebration web experience created with vanilla HTML, CSS, and modern JavaScript.

## Features
- **Interactive Birthday Cake**: 3D styled cake with candles that blow out with smoke and confetti when tapped.
- **Web Audio Melody**: Built-in 8-bit/music box synthesizer playing the "Happy Birthday" tune without any external audio file dependencies.
- **Balloon Pop Wishes**: Floating pastel balloons that pop on click with sweet fortunes & wishes.
- **Mystery Gift Box Unboxing**: Animated ribbon unboxing with particle effects.
- **Personalized Heartfelt Card**: Beautiful handwritten typography with customizable recipient & sender names and personal messages.
- **Shareable Link Generator**: Instant query-string link copier (`?to=...&from=...&msg=...`).

## File Structure
- `index.html`: Main celebration experience page
- `saybyme-birthday.html`: Standalone mirror file
- `style.css`: Glassmorphic, modern responsive styling & micro-animations
- `script.js`: Audio synthesis, canvas confetti, balloon generation, and step transitions
